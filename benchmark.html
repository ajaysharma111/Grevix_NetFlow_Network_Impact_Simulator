NetFlow v1.1 Adaptive Performance Benchmark

Separate benchmark harness for NetFlow v1.1. The frozen v1.0 baseline is preserved in its own folder and archive.

Runs three synthetic graph sizes (100, 500, 1,000 nodes). Each trial uses the same graph and operation sequence. Adaptive mode uses a microtask flush (0 ms configured wait) through 1,000 nodes, then a 1 ms timer above that size.

Method and interpretation

  • Sequential mode applies each update and runs connected-component BFS after every update.
  • Batched mode applies the same updates, waits once for the configured coalescing window, then runs BFS once.
  • Timing includes operation application, graph analysis and the configured or adaptive batch wait. It excludes BroadcastChannel transport, actual Cytoscape rendering, browser paint and network latency.
  • Degradation = ((batched median / sequential median) − 1) × 100. A value at or below 20% meets the numeric threshold for this harness only.
  • Both modes must produce the same final node/link status and reachability summary. A mismatch invalidates that row.

Important: this is a controlled algorithm-level benchmark, not a production end-to-end multi-user measurement. Do not claim the full challenge target is proven from this harness alone.
