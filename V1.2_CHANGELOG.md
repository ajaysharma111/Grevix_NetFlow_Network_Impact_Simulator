# NetFlow v1.2 changelog

- Preserves the v1.1 adaptive build as a separate archive.
- Replaces timer scheduling with `queueMicrotask` for graphs up to 1,000 nodes to avoid browser timer clamping.
- Uses a 1 ms timer only above 1,000 nodes.
- Retains the 32-operation immediate flush threshold and dependency-aware deferred operation handling.
- Updates the benchmark's adaptive policy to match the app.
- Explicitly documents that microtask batching coalesces synchronous bursts but may not combine separate BroadcastChannel tasks.

This is a performance hypothesis to test, not a verified 20% result.

- Adds `node.position` operations: a tab broadcasts a node's final coordinates once when a drag ends, rather than streaming pointer-move events.
- Applies remote positions only when their deterministic last-writer-wins version is newer; defers a position update if its node-add has not arrived yet.
- Remote position application does not re-broadcast, preventing synchronization echo loops.
